# 1) Create Environment

```bat
:: 1) Create Python 3.10 environment
conda create -n rl-sumo-gpu python=3.10 -y
conda activate rl-sumo-gpu
```

# 2) Install the CUDA version of PyTorch (no need to install the system CUDA Toolkit)

> Requirement: A sufficiently recent NVIDIA driver (usually ≥ 535) to run CUDA 12.x.

```bat
:: PyTorch + CUDA 12.1 (synchronize all 3 packages to avoid conflicts)
python -m pip install torch==2.4.1 torchvision==0.19.1 torchaudio==2.4.1 ^

--index-url https://download.pytorch.org/whl/cu121
```

# 3) Install RLlib + reinforcement learning dependencies

```bat

:: RLlib (Ray) – stable version with Gymnasium 0.29
pip install "ray[rllib]==2.9.3" gymnasium==0.28.1 pettingzoo
```
# 4) Install SUMO (binaries) + SUMO-RL

The neatest way is to get SUMO from conda-forge (includes `sumo-gui`, `traci`, …):

```bat
conda install -c conda-forge sumo -y

```

> If you have previously installed SUMO standalone, you **do not need** the `conda install sumo` line; just make sure `SUMO_HOME` points to the correct installation location.

Then install SUMO-RL:

```bat
pip install sumo-rl
```
# 5) Setting SUMO environment variables

If installing SUMO from conda-forge:

```bat
:: Set SUMO_HOME (standard path in conda on Windows)
setx SUMO_HOME "%CONDA_PREFIX%\Library\share\sumo"

:: (Recommended) Add the SUMO bin folder to PATH to call sumo/sumo-gui
setx PATH "%PATH%;%CONDA_PREFIX%\Library\bin"
```

If using a standalone version of SUMO, replace the path with your installation location, for example:

```bat
setx SUMO_HOME "C:\Program Files (x86)\Eclipse\Sumo"
setx PATH "%PATH%;C:\Program Files (x86)\Eclipse\Sumo\bin"
```

# 8) Run PPO with GPU

In your training script, remember to enable GPU for the learner:

```python
from ray.rllib.algorithms.ppo import PPOConfig

config = (
PPOConfig()

.framework("torch")

.resources(num_gpus=1) # << use 1 GPU for learner

.rollouts(num_rollout_workers=4) # rollout workers still run on CPU normally

# .training(... hyperparams ...)

# .environment("4x4grid", env_config={...})

)
algo = config.build()
```

> Check log RLlib: will have a line like `Resources requested: num_gpus: 1`.

#9) Avoiding Conflicts & Tips

* **Do not** mix up installing `torch` from conda and pip. Here we use **pip** for PyTorch → continue using pip for related PyTorch packages.

* If you later need to install additional “native” packages (e.g., `torch-scatter`, `xformers`), choose the correct matching wheel `torch==2.4.1+cu121`.

* Disable spam deprecated warnings (optional):

```bat
set PYTHONWARNINGS=ignore::DeprecationWarning
set RAY_DEDUP_LOGS=0
```

```yaml
- sumo-rl==1.4.5
```


### How to Use

1. Save the above content to `environment.yml`, then run:

```bash
conda env create -f environment.yml
conda activate rl-sumo-gpu
```

2. (Windows) Set the SUMO environment variable (change the path if different):

```bash
setx SUMO_HOME "C:\Program Files (x86)\Eclipse\Sumo"
setx PYTHONPATH "%SUMO_HOME%\tools;%PYTHONPATH%"
```

→ Open a new terminal for the environment variable to take effect.

3. Quick check:

```bash
python - << "PY"
import torch, numpy, pyarrow as pa, pandas as pd, ray, gymnasium, pettingzoo
print("torch", torch.__version__, "cuda?", torch.cuda.is_available())
print("numpy", numpy.__version__)

print("pandas", pd.__version__)
print("ray", ray.__version__)
print("gymnasium", gymnasium.__version__)
print("pettingzoo", pettingzoo.__version__)
PY
```

> Expected: `torch 2.4.1 (cuda? True)`, `numpy 1.26.4`, `pyarrow 6.0.1`, `pandas 1.5.3`, `ray 2.9.3`, `gymnasium 0.28.1`, `pettingzoo 1.24.3`.
