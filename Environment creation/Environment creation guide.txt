Tuyệt vời — mình hướng dẫn bạn tạo **một Conda env mới** cho GPU training (PyTorch CUDA + RLlib + SUMO-RL) trên Windows, kèm kiểm tra nhanh để chắc chắn mọi thứ chạy ổn.

# 1) Tạo môi trường mới

```bat
:: 1) Tạo env Python 3.10
conda create -n rl-sumo-gpu python=3.10 -y
conda activate rl-sumo-gpu
```

# 2) Cài PyTorch bản CUDA (không cần cài CUDA Toolkit hệ thống)

> Yêu cầu: driver NVIDIA đủ mới (thường ≥ 535) để chạy CUDA 12.x.

```bat
:: PyTorch + CUDA 12.1 (đồng bộ cả 3 gói để tránh xung đột)
python -m pip install torch==2.4.1 torchvision==0.19.1 torchaudio==2.4.1 ^
  --index-url https://download.pytorch.org/whl/cu121
```

# 3) Cài RLlib + phụ thuộc học tăng cường

```bat
:: RLlib (Ray) – phiên bản ổn định với Gymnasium 0.29
pip install "ray[rllib]==2.9.3" gymnasium==0.28.1 pettingzoo
```

# 4) Cài SUMO (binaries) + SUMO-RL

Cách gọn gàng nhất là lấy SUMO từ conda-forge (đi kèm `sumo-gui`, `traci`, …):

```bat
conda install -c conda-forge sumo -y
```

> Nếu bạn đã cài SUMO standalone trước đó thì **không cần** dòng `conda install sumo`; chỉ cần bảo đảm `SUMO_HOME` trỏ đúng vị trí cài.

Rồi cài SUMO-RL:

```bat
pip install sumo-rl
```

# 5) Thiết lập biến môi trường SUMO

Nếu cài SUMO từ conda-forge:

```bat
:: Đặt SUMO_HOME (đường dẫn chuẩn trong conda trên Windows)
setx SUMO_HOME "%CONDA_PREFIX%\Library\share\sumo"

:: (Khuyến nghị) Thêm thư mục bin của SUMO vào PATH để gọi sumo/sumo-gui
setx PATH "%PATH%;%CONDA_PREFIX%\Library\bin"
```

Nếu dùng bản standalone của SUMO, thay đường dẫn bằng nơi bạn cài, ví dụ:

```bat
setx SUMO_HOME "C:\Program Files (x86)\Eclipse\Sumo"
setx PATH "%PATH%;C:\Program Files (x86)\Eclipse\Sumo\bin"
```

# 6) Kiểm tra nhanh GPU + SUMO

```bat
python - <<PY
import torch, os

:: kiểm tra binary SUMO
sumo -V

```

# 8) Chạy PPO với GPU

Trong script train của bạn, nhớ bật GPU cho learner:

```python
from ray.rllib.algorithms.ppo import PPOConfig

config = (
    PPOConfig()
    .framework("torch")
    .resources(num_gpus=1)               # << dùng 1 GPU cho learner
    .rollouts(num_rollout_workers=4)     # rollout workers vẫn chạy CPU là bình thường
    # .training(... các hyperparams ...)
    # .environment("4x4grid", env_config={...})
)
algo = config.build()
```

> Kiểm tra log RLlib: sẽ có dòng kiểu `Resources requested: num_gpus: 1`.

# 9) Tránh xung đột & mẹo

* **Không** cài lẫn lộn `torch` từ conda và pip. Ở đây chúng ta dùng **pip** cho PyTorch → tiếp tục dùng pip cho các gói liên quan PyTorch.
* Nếu sau này cần cài thêm gói “native” (vd: `torch-scatter`, `xformers`), hãy chọn đúng wheel khớp `torch==2.4.1+cu121`.
* Tắt spam cảnh báo deprecated (tuỳ chọn):

```bat
set PYTHONWARNINGS=ignore::DeprecationWarning
set RAY_DEDUP_LOGS=0
```

Nếu bạn muốn, mình có thể gửi kèm **một file `requirements.txt`** tối giản đúng version để bạn `pip install -r` trong env mới.

Tuyệt—đây là file **`environment.yml`** sạch (GPU) đã pin phiên bản để tránh mọi xung đột NumPy/PyArrow/RLlib mà bạn gặp:

```yaml
name: rl-sumo-gpu
channels:
  - conda-forge
  - defaults

dependencies:
  - python=3.10.14
  - pip>=24.0
  - setuptools=68.2.2
  - wheel=0.41.2

  # (Tùy chọn) các tiện ích cơ bản hay dùng
  - ca-certificates
  - openssl

  - pip:
      # PyTorch GPU (CUDA 12.1) — dùng index của PyTorch để tự lấy wheel +cu121
      - --index-url https://download.pytorch.org/whl/cu121
      - torch==2.4.1
      - torchvision==0.19.1
      - torchaudio==2.4.1

      # Pin lõi khoa học KHÔNG lên NumPy 2.x (tránh lỗi _ARRAY_API)
      - numpy==1.26.4
      - pandas==1.5.3
      - pyarrow==6.0.1

      # RLlib + phụ thuộc khớp phiên bản
      - ray[rllib]==2.9.3
      - gymnasium==0.28.1
      - pettingzoo==1.24.3

      # SUMO-RL ổn định
      - sumo-rl==1.4.5
```

### Cách dùng

1. Lưu nội dung trên thành `environment.yml`, rồi chạy:

```bash
conda env create -f environment.yml
conda activate rl-sumo-gpu
```

2. (Windows) Thiết lập biến môi trường SUMO (đổi đường dẫn nếu khác):

```bash
setx SUMO_HOME "C:\Program Files (x86)\Eclipse\Sumo"
setx PYTHONPATH "%SUMO_HOME%\tools;%PYTHONPATH%"
```

→ Mở terminal mới để biến môi trường có hiệu lực.

3. Kiểm tra nhanh:

```bash
python - << "PY"
import torch, numpy, pyarrow as pa, pandas as pd, ray, gymnasium, pettingzoo
print("torch", torch.__version__, "cuda?", torch.cuda.is_available())
print("numpy", numpy.__version__)
print("pyarrow", pa.__version__)
print("pandas", pd.__version__)
print("ray", ray.__version__)
print("gymnasium", gymnasium.__version__)
print("pettingzoo", pettingzoo.__version__)
PY
```

> Kỳ vọng: `torch 2.4.1 (cuda? True)`, `numpy 1.26.4`, `pyarrow 6.0.1`, `pandas 1.5.3`, `ray 2.9.3`, `gymnasium 0.28.1`, `pettingzoo 1.24.3`.
